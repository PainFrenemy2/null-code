# null/code

Анимированный сайт-визитка студии **null/code** — «из нуля — в код».

Стек: React 19 · Vite · Framer Motion · Lenis (плавный скролл). Шрифты подключены локально (@fontsource), без Google Fonts.

## Что внутри

- Прелоадер с отрисовкой логотипа и счётчиком
- Hero: фон из символов кода на canvas, который реагирует на курсор, буквы выезжают по одной, текст «расшифровывается», вращающийся бейдж
- Бегущая строка направлений, наклоняется от скорости скролла
- Манифест: слова проявляются по мере скролла
- Карточки услуг с 3D-наклоном и подсветкой под курсором
- Процесс работы: горизонтальный скролл внутри вертикального
- Терминал, который сам «печатает» команды
- Стек технологий, контакты с выбором типа проекта, кнопка в VK
- Кастомный курсор, магнитные кнопки, шум, прогресс-бар скролла, адаптив под мобилки

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
npm run preview  # посмотреть сборку
```

Папку `dist/` можно залить на любой статический хостинг (Vercel, Netlify, GitHub Pages, свой сервер).
